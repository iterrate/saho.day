Privacy

This site sets no cookies and uses no analytics or trackers. It is hosted on GitHub Pages, and GitHub logs visitors’ IP addresses for security (see GitHub’s privacy statement). Our email is handled by Zoho Mail.

If you write to us, we use your email address and what you tell us only to reply. We don’t share it with anyone, and we delete it when you ask.
