About Saho

Saho is a learning platform for Keralam, run by the institutions that use it. It is in development now, and will be released as open-source software.

Why we’re building it

Keralam aims to be a knowledge society. AI is changing what knowledge work looks like, and we want people here to learn how to use these tools in their work and lives on their own terms, without handing that over to a few distant platforms.

Who builds it

Saho is built by Iterrate (OPC) Private Limited, founded by Sangeeth. It is a one-person company for now. You can read more about Sangeeth at sangeethvarma.com.

If you’d like to help build Saho, write to us.

The name

Saho is a call to work together, named for Sahodaran Ayyappan and his ideals of fraternity and equality. saho.day reads as sahoday: rising together.

Saho is built by Iterrate (OPC) Private Limited, Thiruvananthapuram.
